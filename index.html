About Me

A technical founder driven by self-directed learning, practical product delivery, and real-world software engineering.

I'm MD Abu Nafis Niloy, a self-taught programmer and entrepreneur from Bangladesh, currently studying Zoology at Noakhali Science and Technology University.

I started programming around 2020 and became deeply involved in software development around 2022. Since then, I've learned by building — from small experiments and games to business software and AI-powered tools.

In 2024, I started Alpha Soft, a local software agency where I worked directly with more than 30 clients and businesses in Bangladesh. Over time, my interests expanded toward AI and developer tools. I built Alpha AI Agent, an open-source AI agent for Godot 4, and I'm now building QCodeAI, my main startup.

MIT Licensed • Godot Asset Library #5383

In-Editor Agentic Assistance

Pipeline: ANALYZE → EXECUTE → VERIFY

Alpha AI Agent is not a simple chat prompt window. It is an agentic development tool that reads the user's project structure, generates and modifies GDScript, modifies Godot .tscn scene files, connects signals, executes multi-file changes, and verifies execution by inspecting actual runtime logs.

  • Reads full project context & node trees
  • Generates & edits GDScript 2.0
  • Modifies scene files & auto-wires signals
  • Multi-file execution with diff safety
  • One-click snapshot revert manager
  • BYOK Multi-Model API Architecture

Engineering Philosophy

How I Build

Four core principles forged through self-directed development and direct client engagements.

01

Understand the Problem

I start by understanding what the user or business actually needs before jumping into implementation or choosing tech stacks.

02

Design the System

I think about how the different pieces — databases, APIs, state machines, and interfaces — need to work together sustainably.

03

Build the Product

I prefer building complete working systems rather than isolated demos or fragmented snippets that never see real users.

04

Iterate from Reality

Working with real clients and users has taught me to adapt products based on actual requirements and feedback, not assumptions.
