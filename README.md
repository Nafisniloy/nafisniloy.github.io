## How I build

1. **Understand the problem** - Start with the actual user or business need.
2. **Design the system** - Think through databases, APIs, state, and interfaces together.
3. **Build the product** - Prefer complete working systems over isolated demos.
4. **Iterate from reality** - Improve products through real requirements, usage, and feedback.
